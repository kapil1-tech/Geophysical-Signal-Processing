# Geophysical Signal Processing for Seismic Event Detection

## Project Overview

This project demonstrates the application of signal processing techniques to seismic data for automatic event detection.

## Objective

To detect seismic events from noisy seismic signals using bandpass filtering and the STA/LTA (Short-Term Average / Long-Term Average) algorithm.

## Methodology

1. Generate synthetic seismic data.
2. Apply a bandpass filter to remove unwanted noise.
3. Compute the STA/LTA ratio.
4. Detect seismic events using a threshold.
5. Visualize the results.

## Technologies Used

* Python
* NumPy
* SciPy
* Matplotlib
* Jupyter Notebook

## Results

The project successfully identifies seismic events from a noisy signal using signal processing techniques.
